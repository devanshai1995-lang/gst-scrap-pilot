# GST Scrap Pilot

A launch-ready project scaffold for a Chrome extension and website focused on GST compliance workflows.

## Getting started

```bash
npm install
npm run build
```

## Run website locally

```bash
npm run dev:website
```

## Folder overview

- `chrome-extension/` - packaged extension source
- `website/` - static website landing page
- `docs/` - additional product documentation
